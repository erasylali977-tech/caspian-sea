# Океанская музыка / Ocean Audio

Поместите сюда файл `ocean-ambience.mp3` с фоновой музыкой океана.

Рекомендуемые параметры:
- Формат: MP3
- Битрейт: 128-192 kbps
- Длительность: 2-5 минут (зацикливается)
- Тип: Подводные звуки, океанская атмосфера

Бесплатные источники музыки:
- https://freesound.org/ (поиск: underwater, ocean ambience)
- https://incompetech.com/
- https://www.youtube.com/audiolibrary
